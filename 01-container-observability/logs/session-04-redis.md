# Step 1: Deploy Azure Managed Redis
There are 2 options in Azure for Redis; Azure Cache for Redis, or Azure Managed Redis. The former is the older and move documented version, and likely the one people are still using, while Azure Managed Redis is the new version by Microsoft that will be recommended going forward, but has less documentation due to this. For the sake of being as current as possible with this lab, I am using Azure Managed Redis.

I deployed my Azure Managed Redis instance via the Portal.
